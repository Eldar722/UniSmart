# UniSmart — AI Datahub для вузов Казахстана

Хакатон-проект: веб-платформа с единым datahub по вузам Республики Казахстан. Помогает абитуриентам и студентам подбирать подходящие университеты и специальности с помощью ИИ-персонализации.

## Функциональность

- Единая база данных вузов и специальностей РК
- AI-подбор вузов/специальностей под профиль студента
- Roadmap-логика персонализации рекомендаций

## Стек

- Backend: см. `/backend`
- Frontend: см. `/frontend`

## Структура

```
backend/                          # серверная часть
frontend/                         # клиентская часть
ROADMAP_PERSONALIZATION.md        # описание логики персонализации рекомендаций
test_smart_roadmap_direct.py      # тест AI-подбора roadmap
```

## Статус

Хакатон-проект. Реализовано с использованием AI-инструментов для ускорения разработки; архитектурные решения и постановка задачи — в рамках командной работы.
