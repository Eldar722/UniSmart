# Confectionery MVP — интернет-магазин кондитерских изделий

Групповой учебный проект: минимальный жизнеспособный продукт (MVP) для интернет-магазина кондитерской продукции. Первый серьёзный командный проект — реализован совместно небольшой командой.

## Стек

- Python
- Django
- HTML, CSS

## Функциональность

- Каталог товаров
- Корзина покупок
- Оформление заказа (реализовано частично, в процессе доработки)

## Статус

MVP в разработке. Часть функциональности (оформление заказа) не доведена до конца — базовая логика каталога и корзины работает.

## Команда

Разработано в составе учебной группы в рамках командного проекта.
